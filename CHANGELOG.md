# Changelog

All notable changes to this project are documented in this file.

## [1.0.0] - 2026-09-08

### Added

- 25 configurable free-form local device attributes
- ADMX-backed machine policies for Microsoft Intune
- English ADML language resources
- Machine-wide registry storage
- PowerShell helper for reading one or all configured attributes
- Five generic usage examples
- Microsoft Intune import and usage documentation
- FAQ with verified policy behavior, cleanup, conflict and value-length details
